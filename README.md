# Grid Banner Export – v1.1

Turn one wide photo into **3 Instagram posts that form a seamless banner** in your profile grid – with one Photoshop script.
Mach aus einem breiten Foto **3 Instagram-Posts, die im Profil einen nahtlosen Banner bilden** – mit einem Photoshop-Skript.

**Download:** [English](../../releases/latest/download/Grid-Banner-EN.zip) · [Deutsch](../../releases/latest/download/Grid-Banner-DE.zip)

## Requirements · Voraussetzungen
- Adobe Photoshop on **macOS or Windows** · Adobe Photoshop unter **macOS oder Windows**
- Tested on macOS with Photoshop 2026 – Windows not tested yet, feedback welcome
- Getestet auf macOS mit Photoshop 2026 – Windows noch ungetestet, Rückmeldungen willkommen

## Install · Installation
| | |
|---|---|
| **macOS** | Unzip → `bash install.sh` in Terminal (asks for your password) |
| **Windows** | Copy `Grid-Banner-Export.jsx` to `C:\Program Files\Adobe\Adobe Photoshop 2026\Presets\Scripts\` |

Restart Photoshop → **File → Scripts → Grid Banner Export**.
Full guides (EN/DE) are inside each package · Ausführliche Anleitungen liegen in jedem Paket.

## How it works
Posts are uploaded as 4:5, but the profile grid only shows the centre 3:4. The script cuts three overlapping posts
from a 3105 × 1350 area – seamless in the grid, complete when opened. Post right → middle → left, then pin all three.
